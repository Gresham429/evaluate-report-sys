# 房地产估价报告生成系统

把估价师的「实勘表、比较法」Excel 工作簿，自动转成符合公司格式的 Word 估价报告。
支持 **农用 / 办公 / 商业** 三类，每类一套模板。

## 设计文档

`docs/superpowers/specs/2026-07-15-房地产估价报告生成系统-design.md`

## 核心原则

- **Excel 的公式是既定正确的，系统只读不改** —— 不重算任何数值，只读计算缓存值
- **运行时零 AI** —— 同一份输入永远产出同一份输出
- **校验只提示，不阻断** —— 是否为问题由估价师判断
