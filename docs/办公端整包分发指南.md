# 办公端整包分发指南 — 一次配好、每人解压即用

> 面向 **IT / 管理员**。估价师不用读这份；他们只需最后一节《估价师快速卡》。
> 目的：让不懂电脑的估价师用上「联公司钉钉多维表」的办公端，而**不碰任何配置**。

## 核心：麻烦只发生一次，不落在估价师头上

联多维表要在 exe 旁放一份填好的 `.env`（AppKey/Secret、baseId、四个 sheetId）。
这份 `.env` **全公司同一份、不是每人一份**——填一次，所有人共用。分工如下：

| 谁 | 会不会电脑 | 做什么 | 频率 |
|---|---|---|---|
| IT / 管理员 | 懂一点 | 填一次 `.env` → 跑脚本打成「整包」 | **一次** |
| 每个估价师 | **完全不用懂** | 解压 → 双击 exe → 手机扫码登录 | 日常 |

## 一次性：做出整包（IT，约 5 分钟）

**步骤 1 — 拿交付包**
从 GitHub Releases（当前 `v1.1.3`）或 Actions 产物下载 Windows 交付 zip
（`appraisal-report-system-windows.zip`，里面是 exe + 模板 + 使用说明）。

**步骤 2 — 准备填好的 `.env`**
- 已有现成的：仓库 `dist/office部署.env` 就是填好的真实 `.env`（含 app secret，已 gitignore）。
- 从零填：复制 `deploy/office.env.example` → 填 9 个值：
  - `承载后端=多维表`（固定）
  - `YIDA_APP_KEY` / `YIDA_APP_SECRET`：钉钉开放平台「企业内部应用」的 AppKey/AppSecret
  - `NOTABLE_BASE_ID`：多维表 baseId；`NOTABLE_OPERATOR_ID`：操作人 **unionId**
  - 四个 sheetId：`NOTABLE_SURVEY_SHEET / INSTANCE_SHEET / BASETABLE_SHEET / LEDGER_SHEET`
  - 值从哪拿见 [`宜搭对接配置.md`](宜搭对接配置.md) 与多维表承载层 design。
- ⚠️ **别填 `OFFICE_OPERATOR_ID`**：填了会让每台机共用同一身份、把「只看自己」搞坏。
  办公端靠扫码登录识别本人。脚本会自动提醒这条。

**步骤 3 — 跑脚本产出整包**
```bash
uv run python tools/make_office_bundle.py \
    路径/appraisal-report-system-windows.zip \
    路径/填好的.env \
    --out dist/
```
产出 `dist/appraisal-report-system-office-configured-windows.zip`——exe 旁已放好 `.env`，
估价师解压双击即联多维表。

**脚本自动挡的坑**（体检不过就不打包，`--force` 可强行跳过但不建议）：
1. `承载后端` 不是 `多维表` → 整包会退回本地模式（无同步/无登录/无门禁）。**阻断**。
2. 9 个必需键缺任一 / 仍是占位值（如 `你的AppKey`）→ 连不上多维表。**阻断**。
3. 值里含行内 `#` 注释 → 程序不剥离、会把注释吞进值里连不上。**提醒**。
4. 误填 `OFFICE_OPERATOR_ID` → 破坏「只看自己」。**提醒**。
5. 整包里混进中文名松散文件（§坑7，会被国产解压软件解乱码）→ **提醒**。

## 分发给估价师

把 `dist/appraisal-report-system-office-configured-windows.zip` 通过**内部渠道**
（钉钉/内网/U 盘）发给每个估价师。**含 app secret，绝不要传 GitHub / 公网 / 群里公开。**

## 估价师快速卡（IT 把这一段转发给估价师即可）

> **三步就能用，全程不用配置：**
> 1. 把收到的压缩包**完整解压**到桌面一个文件夹（别在压缩软件里直接双击 exe）。
> 2. 双击 `appraisal-report-system.exe`，浏览器会自动打开。
> 3. 页面提示登录 → 用**手机钉钉扫码** → 点授权 → 开始出报告。
>
> 关掉软件后下次打开要再扫一次码，这是正常的。遇到问题找公司 IT。

## 升级怎么办

出了新版 exe，IT 重复「步骤 1→3」产一个新整包发下去即可；估价师的实例库/草稿在自己
机器的 `data/` 里，解压新整包**不会**覆盖（交付包刻意不带 `data/`）。
