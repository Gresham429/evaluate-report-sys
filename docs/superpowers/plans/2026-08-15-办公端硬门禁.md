# 办公端硬门禁 + 使用授权（用户需求）

- 日期：2026-08-15
- 需求：办公端**必须扫码登录**才能用;登录后**校验是否在「允许使用」名单**,不在则挡住整个软件。
- 只在**钉钉模式**（`承载后端=多维表`）生效;本地单机模式（内部版,无钉钉）不受影响、照常用。

## 授权模型

- 名单 env `OFFICE_ALLOWED_USERS`(userid,逗号/空格分隔),同 `OFFICE_ADMINS` 风格。
- `is_authorized()` = **有身份**（`current_operator()` 非空——生产配置不设 `OFFICE_OPERATOR_ID` 故=必须登录）
  且（**名单为空→放行任何已登录者**（靠钉钉应用可见范围兜） 或 operator∈名单 或 管理员）。
- 生产（无 fallback）:不登录 operator="" → 未授权 → 挡。登录后 operator 有值 → 过名单判定。
- 单测（`office_operator` 打桩有值=fallback):authorized → 不破坏现有 survey 测试。

## 改动

- `config.office_allowed_users()`（新,env `OFFICE_ALLOWED_USERS`）。
- `session.is_authorized()`（新,上面的判定）。
- `/api/me` 加 `authorized`(是否可用) + `gated`(=`use_notable()`,门禁是否生效)。
- **中间件**:`use_notable()` 且路径非豁免 且 未授权 → **403**。豁免:`/`、`/api/me`、`/api/online`、
  `/auth/*`、`/favicon.ico`。防前端被绕过。
- **前端门禁遮罩**:载入查 `/api/me`——`gated && !authorized` 时全屏挡住:未登录→「请扫码登录后使用」+登录按钮;
  已登录但未授权→「您无权使用本软件,请联系管理员开通」+退出。`authorized` 或非 gated → 正常显示。

## 测试

- config:名单解析（空/多个/admin）。
- session:`is_authorized` 各分支（无身份/名单空放行/在名单/不在名单/admin）。
- 中间件:钉钉模式未授权→403、豁免路径放行、本地模式不挡；授权后放行。
- /api/me:authorized/gated 字段。
- 前端:Playwright 冒烟——未登录见门禁、（模拟授权后）见应用。

## 部署配套

- `deploy/office.env.example` + 指南加 `OFFICE_ALLOWED_USERS` 说明（空=任何登录者;填=只这些人）。
- 生产配置不设 `OFFICE_OPERATOR_ID`（已如此）→ 硬性必须登录。
