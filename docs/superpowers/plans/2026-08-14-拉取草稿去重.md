## 问题

拉同一份「已提交」问卷 N 次 = N 份草稿，且草稿与问卷失联。

**根因**：`/api/survey/pull` 只回预填 payload；前端 `applyPrefillBody` → `openForm(category)`
在 `index.html:889` 把 `draftId=null`（新建表单路径），随后自动保存 → 每次 POST `{id:null}`
→ 后端新建一份。草稿不带任何问卷链接，故无从判重、也无从回溯来源。

## 设计（最小、逻辑留 Python、可单测）

判重**判定放后端**（可单测），前端只留一条薄分支（复用既有「续填」路径）。

1. **`Draft`/`DraftInfo` 加 `问卷ID: str = ""`**（`model.py`）
   - 默认 `""`：旧草稿文件、手建草稿（新建/导入 Excel）天然不参与判重。
   - `Draft.new(..., 问卷ID="")`；`info()` 透传。
2. **`DraftStore.find_by_survey(问卷ID) -> DraftInfo | None`**（`store.py`）
   - 空 `问卷ID` 一律回 None（绝不误并手建草稿）。
   - 扫 `list_all()`（已按新→旧排）返回首个命中；多份历史重复时取最新那份。
   - `to_dict`/`from_dict` 持久化 `问卷ID`（缺键兜底 `""`，向后兼容）。
3. **`POST /api/drafts` 收可选 `问卷ID`**（`app.py`）→ 透传 `Draft.new`，给拉取新建的草稿打标。
4. **`GET /api/survey/pull` 只读查已有草稿**（`app.py`）
   - 返回 payload 增 `existing_draft_id`：命中 = 该草稿 id，否则 `None`。
   - pull 仍是**读**（不建草稿）；建草稿照旧走 saveDraft，判定权在 Python。
5. **前端薄分支**（`index.html`）
   - 拉取后若 `existing_draft_id`：走既有「续填」加载该草稿（保住已填内容），提示「该问卷已有在填草稿，已为你续上」。
   - 否则：照旧预填；新增模块态 `currentSurveyId = questionnaire_id`，`saveDraft` 带上 `问卷ID`。
   - `currentSurveyId` 在三条 openForm 路径各自设：拉取=问卷ID、续填=草稿.问卷ID、新建/导入=`''`。

## 幂等保证

首拉问卷 X：无已有草稿 → 新表单 → saveDraft 打标 d1(问卷ID=X)。
再拉 X：pull 命中 d1 → `existing_draft_id=d1` → 前端续填 d1（不覆盖已填）。→ 每问卷恰好一份草稿。

## 测试

- 单元（`test_drafts.py`）：问卷ID 往返、缺键兜底 `""`、`find_by_survey` 命中/空查/无命中/多份取新。
- 端点（`test_web_survey.py`）：pull 无已有草稿回 `None`；POST 打标后再 pull 回该 id（端到端幂等）。
