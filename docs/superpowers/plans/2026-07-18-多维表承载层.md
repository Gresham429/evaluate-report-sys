## Errors Encountered
- 循环导入：store→factory→(package __init__→store)。解法：factory 延迟到 Store.__init__ 内导入。
- 领号 insert 空 fields → HTTP400 "record.fields must not be empty"。解法：占位行至少带一字段。
- 冒烟 ② 领号还需台账表建『报告序号』自动编号字段（多维表 UI 一键加；或校准 create_field 的 autonumber type 字符串）。

## 关键决策（承 spec）
- 整份 payload 存一个长文本字段 `快照`（不摊列）；另存索引/键字段。
- 切换放 Store `__init__` 默认后端（3 处改），不碰 app.py 15 个构造点；默认本地、conftest 不触发。
- Instance save 只增/改不删（共享库不因本地删除删公司数据）。
- 报告编号用多维表"自动编号"字段。
