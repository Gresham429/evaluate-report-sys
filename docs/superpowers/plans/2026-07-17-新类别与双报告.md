# 4 个新类别 + 委托评估协议书 + 下载点选 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把系统类别从 3 扩到 7（+住宅/工业/停车场用地/建设用地），并在出报告时同时产出「房地产估价报告 + 委托评估协议书」两份文书，前端点选下载。

**Architecture:** 新类别复用现有比较法引擎与抽取层（4 份新 Excel 结构一致），报告映射到「房产/土地」两个新 shape 模板；协议书做一份类别无关的通用模板 + 独立 render 路径。新类别只锁**算术金样**（引擎重算=Excel 缓存），报告正文只做结构渲染并显式标注须估价师终审（Approach A）。

**Tech Stack:** Python 3.13、openpyxl、docxtpl/python-docx、FastAPI、原生 JS 单文件前端、pytest、uv。

## Global Constraints

- 铁律 #1 金样精确复现：现有三类正文金样一字不动；新类别锁算术金样（`compute().评估结果==Excel T39`、`.离散度==Excel X37`、`annual_value()==一览表 L 列`）。
- 铁律 #2 知识在 Excel、算术在 Python：不改基础表、不回写 Excel。
- 铁律 #3 运行时零 AI：渲染/算术全程无模型调用。
- 铁律 #4/#5 台账只增不改、快照自洽：协议书不进台账，台账逻辑一律不动。
- §5 坑 7：随包发出、按名字找的标识一律 ASCII —— 新模板文件名 ASCII；**Category 值仍是中文**（`住宅/工业/停车场用地/建设用地`），遍布 JSON/台账，是数据身份。
- §5 坑 10/11：金样只查缺失不查多余、实勘表有「0」残留行 —— 结构渲染测试须断言无垃圾行。
- §5 坑 3：新增用到存储的 web 测试须被 `conftest._isolate_data_dirs` 兜住（默认已 autouse）。
- 前端是单文件原生 JS，改 `index.html` 后须真人浏览器实测（单元测试测不到 UI）。
- 编码规范：TDD、全类型标注、不裸 except、logger 不用 print、中文注释讲「为什么」。
- 每个任务结束 `uv run pytest && uv run mypy src/ && uv run ruff check .` 全绿再提交。

```python
"""从现有已 jinja 化模板派生两个通用 shape 模板，替换残留硬编码样例值。

office.docx→lease_building.docx（房产）、farmland.docx→lease_land.docx（土地）。
残留样例值（价值时点日期、机构住址、法人/查勘人姓名）替换为 build_context
已提供的 {{ 变量 }}，使模板真正通用。纯脚本、可重复运行。
"""
import shutil
from pathlib import Path
from docx import Document

TEMPLATES = Path(__file__).resolve().parents[1] / "templates"

# 已 build_context 提供对应变量的残留硬编码：精确原文 → jinja token
BUILDING_REPLACE = {
    "2026年3月26日": "{{ value_date_cn }}",
    "浙江省杭州市萧山区金城路685号综合楼三楼": "{{ client_address }}",
    "余峰": "{{ legal_rep }}",
}
LAND_REPLACE = {
    "2026年4月20日": "{{ value_date_cn }}",
    "杭州市钱塘区义蓬街道义蓬村": "{{ client_address }}",
    "周国祥": "{{ legal_rep }}",
    "郑伟娜": "{{ surveyor }}",
}


def _replace_everywhere(doc: Document, mapping: dict[str, str]) -> None:
    """段落与表格单元格内做整串替换。跨 run 的串先合并到首 run 再替换。"""
    def fix_paragraph(p) -> None:
        text = p.text
        if not any(k in text for k in mapping):
            return
        for k, v in mapping.items():
            text = text.replace(k, v)
        for r in p.runs:
            r.text = ""
        if p.runs:
            p.runs[0].text = text
        else:
            p.add_run(text)
    for p in doc.paragraphs:
        fix_paragraph(p)
    for tb in doc.tables:
        for row in tb.rows:
            for cell in row.cells:
                for p in cell.paragraphs:
                    fix_paragraph(p)


def build(src_name: str, dst_name: str, mapping: dict[str, str]) -> None:
    dst = TEMPLATES / dst_name
    shutil.copy(TEMPLATES / src_name, dst)
    doc = Document(dst)
    _replace_everywhere(doc, mapping)
    doc.save(dst)
    print("wrote", dst)


if __name__ == "__main__":
    build("office.docx", "lease_building.docx", BUILDING_REPLACE)
    build("farmland.docx", "lease_land.docx", LAND_REPLACE)
```

```python
"""委托评估协议书渲染。四类通用，与估价报告解耦。

协议书无估价算术，不进台账（快照自洽只管估价）。收费合计由估价师手填，
大写用 prose.capital 生成——法律文书里大写作准，不得算错。
"""
import logging
from pathlib import Path
from docxtpl import DocxTemplate
from src.model import Project
from src.paths import templates_dir
from src.prose.capital import to_capital

logger = logging.getLogger(__name__)
__all__ = ["build_agreement_context", "render_agreement", "AGREEMENT_TEMPLATE"]

AGREEMENT_TEMPLATE = "entrustment_agreement.docx"


def build_agreement_context(project: Project, fee_total: int) -> dict[str, object]:
    """组装协议书上下文。fee_total 为估价师手填的收费合计（整数元）。"""
    return {
        "client": project.client,
        "fee_total": f"{fee_total:,}",
        "fee_capital": to_capital(fee_total),
    }


def render_agreement(project: Project, fee_total: int, output: Path,
                     templates_dir_override: Path | None = None) -> Path:
    """渲染协议书 docx。"""
    directory = templates_dir_override or templates_dir()
    template_path = directory / AGREEMENT_TEMPLATE
    if not template_path.exists():
        raise FileNotFoundError(f"协议书模板不存在：{template_path}")
    document = DocxTemplate(template_path)
    document.render(build_agreement_context(project, fee_total))
    output.parent.mkdir(parents=True, exist_ok=True)
    document.save(output)
    logger.info("已生成委托评估协议书 %s（收费 %d 元）", output.name, fee_total)
    return output
```

```javascript
async function downloadDoc(url, form, okMsg) {
  const status = $('gen-status');
  const response = await fetch(url, { method: 'POST', body: form });
  if (!response.ok) { status.textContent = '生成失败：' + (await response.text()); return; }
  const blob = await response.blob();
  const cd = response.headers.get('content-disposition') || '';
  const m = cd.match(/filename\*?=(?:UTF-8'')?"?([^\";]+)"?/i);
  const filename = decodeURIComponent(m ? m[1] : 'report.docx');
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob); a.download = filename; a.click();
  URL.revokeObjectURL(a.href);
  status.textContent = okMsg + filename;
}

$('generate-agreement').addEventListener('click', async () => {
  if (!currentProject) { $('gen-status').textContent = '请先完成项目数据'; return; }
  const form = new FormData();
  form.append('project', JSON.stringify(currentProject));
  form.append('fee_total', String($('fee-total').value || 0));
  await downloadDoc('/api/agreement', form, '已下载：');
});
```
