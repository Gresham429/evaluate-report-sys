# 设计：移动端实勘问卷（现场采集 + 智能预填）

- 日期：2026-07-18
- 状态：**平台已被修订取代**——见 `2026-07-19-智能实勘问卷-design.md`（平台从宜搭改为「钉钉小程序 + serverless」，因宜搭专业版 5988/年公司未订）。本文 §2 的产品决策（一人到底 / 随处填自主 / 预填只覆盖地理因素 / 算术留 Python）仍有效并被新设计沿用；本文的宜搭实现路径作废。仅设计、未写代码。
- 关联：[钉钉全公司同步 design §7](2026-07-17-钉钉全公司同步-design.md)（本文是其"移动问卷"专项的展开）、
  [实勘问卷·地理因素与话术](../../实勘问卷-地理因素与话术.md)（预填因素清单 + 话术模版）。

## 0. 一句话

把实勘表搬到手机上：估价师现场用钉钉里的一张宜搭问卷填写（地图接口把地理类因素的**事实**预填、加速），
数据落宜搭表；回办公室本地程序拉这份数据，走原有的选实例→比较法→出报告管线。**问卷只管采集，算术与
渲染仍在 Python 引擎**（金样红线）。

## 1. 背景

现状：出报告靠"表单输入或导入 Excel 实勘表"，都在办公室本地程序里。现场信息靠人事后录入，慢且易漏。
目标：现场手机直接采集，减少二次录入；地理类因素用地图接口预填事实。属钉钉全公司同步的一块采集前端。

## 2. 已敲定决策（2026-07-18 brainstorm）

1. **一人到底**：实勘人员 = 估价师本人，手机上从头填到尾。填问卷的人即有资格下判断的人，
   §8「执业判断归人」天然满足——无需角色移交。
2. **一张问卷、随处填、自主**：不硬分"现场/办公"字段。手机现场填一部分 → **暂存** → 回办公室 PC
   打开同一份**续填/补因素档次** → **提交**。问卷**软提示**"建议现场填"（周边/现状/照片），但不强制；
   愿意现场全填完也行。本地程序只读"**已提交**"的那份出报告。
3. **智能预填只覆盖"地理位置类因素"**：逐类清单 + 每因素话术模版见
   [实勘问卷·地理因素与话术](../../实勘问卷-地理因素与话术.md)。**接口只填事实、档次估价师定**，话术待估价师定稿。
4. **算术/渲染仍在 Python 引擎**：比较法（金样红线 铁律 #1）与 docx 渲染不挪进宜搭；问卷是采集前端。

## 3. 数据流

```
现场（手机·钉钉宜搭问卷）
  领报告编号（宜搭流水号）→ 取一次 GPS → 地图接口预填地理因素事实 → 估价师核对/改/定档次 + 拍照 → 暂存
回办公室（PC 浏览器同一份宜搭问卷）
  续填/补因素档次 → 提交（状态=已提交）
本地程序（Python，办公室）
  拉「已提交」问卷 → 映射成实勘表数据（基本信息/28 因素档次/资产状况描述/照片）
  → 选可比实例 → 比较法重算(Python) → 出报告 + 台账
```

## 4. 铁律处置

- **#1 金样**：比较法留 Python，问卷不碰算术。
- **#3 运行时零 AI**：地图 POI 是确定性数据检索、发生在**采集**阶段；报告生成阶段无模型调用，可复现不变。
- **#5/#6 快照自洽/存当时那份**：预填事实经估价师确认后**随实勘数据存进快照**，出报告用存的那份，
  **不在渲染时重查接口**（否则同份报告今明查出的周边不同）。
- **#7/#8 不替他填、判断交给人**：接口只给事实（附近有几条公交、最近地铁多远），
  **因素档次（好/中/差）估价师自己定**，系统不做"距离→档次"映射、不推荐。
- **#9（钉钉改写版）**：问卷数据进公司受控的宜搭；GPS 坐标发第三方地图服务属外部调用，须合规确认。

## 5. 待做（未来 spec/实现，均未动）

- **问卷字段 ↔ 实勘表映射**：宜搭问卷每个字段对到 `extractor` 现有的实勘表字段（基本信息 19 项、
  28 因素档次、资产状况逐因素描述、照片）。这是"本地拉取适配器"的翻译表。
- **宜搭问卷表搭建**：在付费组织里建问卷表单（字段 + 因素档次下拉 + 附件/照片 + 暂存/续填）。
  待验：宜搭表单**暂存草稿 + 换设备续填**是否支持。
- **本地拉取适配器**：本地程序按 formUuid 拉"已提交"问卷记录 → 组装成 `Project`/实勘数据喂管线
  （复用钉钉同步那套宜搭 OpenAPI 客户端）。
- **地图接口选型**：高德/百度 POI 周边搜索 + 逆地理编码；距离口径（直线 vs 驾车）统一；预填字段标"接口获取、请核对"、可改。
- **话术定稿**：[地理因素与话术](../../实勘问卷-地理因素与话术.md) 的措辞须执业估价师逐条定稿（§8）。

## 6. 依赖与阻塞

- **宜搭付费组织**：同钉钉同步——免费版无 OpenAPI，问卷表的程序化读写要专业版（见钉钉 design §0/§2b）。
- **执业估价师**：话术定稿、"距离→档次"不由系统映射的把关。
- **合规**：坐标发地图服务、数据进宜搭。

## 7. 谁能拍板什么

- 产品/工作流（一人到底、随处填自主、预填范围）：用户 —— §2 已定。
- 执业（话术用语、档次判断）：执业估价师。
- 合规（坐标外发、数据进宜搭）：贵司合规。
