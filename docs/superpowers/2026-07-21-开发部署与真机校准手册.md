# 开发部署与真机校准手册（钉钉小程序 + broker + 办公端）

> 2026-07-21。本会话累计的**代码侧已全部完成并 push origin/main**；本手册＝**部署/上传/校准/验收的操作清单**，下次直接照这个走，不必翻聊天记录。
> 相关：账号与密钥来源见 `docs/superpowers/2026-07-19-智能实勘问卷-二期账号与部署指南.md`；broker 细节见 `serverless/survey_broker/README.md`。

---

## 0. 系统三部分

```
① 桌面端（本机 exe）        分步填写 + 比较法计算 + 导出双报告；承载后端=多维表时与钉钉同步
② serverless broker         阿里云函数计算(FC)，前端不持密钥，一切写多维表/高德经它中转
③ 钉钉小程序（手机）        现场采集：19基本字段 + 28逐因素 + 照片 + GPS地图预填 + 离线补传
```

数据流：小程序 → broker → 钉钉多维表「实勘问卷」表 → 办公端拉「已提交」预填出报告。

## 1. 代码现状（截至 2026-07-21，均在 main）

**broker actions（`serverless/survey_broker/handler.py::dispatch`）**：
`whoami`（免登）· `saveDraft` · `loadDraft` · `submit` · `deleteDraft` · `prefillGeo`（地图事实）· `uploadPhoto`（照片→钉钉→URL）。

**小程序页面（`miniprogram/`）**：入口页（免登 + 未提交草稿可删 + 已提交按类别分组不可删）· 表单页（19字段，标签对齐实勘表）· 现场采集页（拍照）· 逐因素页（28因素描述+档次下拉 + 地图预填自动填区位描述）。

**离线**：改动即本地存盘、断网暂存/提交不丢、联网自动补传（照片+问卷）。

**GPS 地图预填覆盖的高可靠区位因素**：地铁 · 公交 · 公共服务设施 · 离高速口 · 离城中心/重要场所 · 停车场/货车停车 · 就近道路（通达度/临路/临街道路等级）· 离水源地。只填**描述**（空的才填、可改），**档次仍人工选**（铁律 #7）。

## 3. 重部署 broker（改了 `serverless/` 或 `src/dingtalk/notable.py` 就要做）

```bash
cd 估价报告系统
uv run python serverless/package.py     # 生成最新 serverless/dist/survey_broker_fc.zip（12 文件，零依赖）
```

自检 zip 是否含最新代码（可选）：
```bash
unzip -p serverless/dist/survey_broker_fc.zip serverless/survey_broker/amap.py | grep -oE '"(center|highway|parking|water|roads)":'
```

阿里云 FC 控制台：
1. 现有函数 → **上传** `serverless/dist/survey_broker_fc.zip` → **部署**。
2. 确认启动命令仍为 `python3 -m serverless.survey_broker.server`、监听端口 `9000`（环境变量不用改）。

命令行冒烟（不用手机）：
```bash
BASE=https://zhenghee-report-bmpupipvct.cn-hangzhou.fcapp.run
curl -sS "$BASE/"                                                   # 期望 {"ok":true}
curl -sS -X POST "$BASE/" -H 'Content-Type: application/json' \
  -d '{"action":"prefillGeo","payload":{"lng":120.21,"lat":30.25}}' # 期望 地址 + center/highway/parking/water/roads
```

## 4. 上传 / 发布小程序（改了 `miniprogram/` 就要做）

- **⛔ CLI 路线走死**：`ding upload` 硬性要 app scope `qyapi_alipay_eapp_base`（开不出来），作废。
- **✅ GUI 路线（唯一可行）**：装「钉钉开发者工具」IDE → 扫码登录（管理员/开发者）→ 打开目录 `miniprogram/` → 编译预览无红错 → 右上「上传」，**版本号 +1**（如 1.0.2）。
- 钉钉后台「版本管理与发布」→ 设**体验版** → 加体验成员 → 手机钉钉工作台打开。
- 钉钉后台「开发配置 → 安全设置」确认 **HTTP 可信域名 = broker 域名**（`zhenghee-report-bmpupipvct.cn-hangzhou.fcapp.run`）；权限管理确认已开**免登/通讯录个人信息读、定位、拍照**。

> ⚠ broker 与小程序**任一改动都要各自重部署/重上传**；两者版本要一起更新，否则会出现「小程序有新映射但 broker 返回旧字段」的情况（表现：地图卡缺 行政中心/高速口/停车场/水源/道路 那几行）。

## 7. 真机验收清单（体验版走一遍全链路）

- [ ] 入口页免登显示「填报人:姓名」
- [ ] 新建 → 选类别 → 19 字段（标签与实勘表一致）
- [ ] 逐因素页：选档次（下拉，来自基础表）+ 填描述；点「地图预填」→ **区位因素描述自动补上**（离城中心/高速口/水源/停车/道路…，档次仍手选）
- [ ] 现场采集页：拍照 → 缩略图「已传」；断网拍照 → 「待传」不丢
- [ ] 暂存 / 切后台重开恢复 / 跨设备续填
- [ ] 断网提交 → 「已存本机，联网自动补传」；联网后自动补传 + 提交
- [ ] 提交成功 → toast + 自动退回入口页 → 该条进「已提交·类别」分组
- [ ] 删一份未提交草稿 → 确认 → 列表移除 + 多维表对应行删除；已提交件无删除入口
- [ ] 办公端「从实勘问卷拉取」→ 见该问卷 → 预填出报告（含照片 URL + 逐因素）

## 8. 回滚

- **broker**：FC 控制台切回上一个版本；或 `git revert <commit>` 重打包重传。
- **小程序**：钉钉后台版本管理回退体验版。
- **办公端**：删 `.env` 里 `承载后端=多维表` 两行即回本地模式。
