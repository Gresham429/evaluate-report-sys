|---|---|
| `DINGTALK_APP_KEY` / `DINGTALK_APP_SECRET` | 钉钉小程序 Client ID / Secret(与承载层同一企业内部应用) |

| `AMAP_KEY` | 高德 **Web 服务** Key |
