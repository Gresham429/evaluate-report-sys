# 宜搭建表清单 · 「台账」表（照着点，约 5 分钟）

> 给你在宜搭界面里一条一条点着建。先只建这一张，跑通了再照葫芦画瓢建其余 3 张。
> 建表这步只能在宜搭界面点（接口不管建表），下面尽量写细。

## 第一步：新建一个表单/数据表

- 在宜搭里「新建应用」（或用你已有的测试应用）→ 里面「新建表单」。
- 表单名就叫 **台账**。

## 第二步：加下面这些字段（一个一个加，括号里是"选哪种字段类型"）

| 序号 | 字段名（照抄） | 选这种字段类型 | 备注 |
|---|---|---|---|
| 1 | 记录号 | 单行文本 | 每条台账的唯一号，程序生成 |
| 2 | 报告编号 | 单行文本 | 先普通文本即可 |
| 3 | 类别 | 单选 | 选项填这七个：农用、办公、商业、住宅、工业、停车场用地、建设用地 |
| 4 | 生成时间 | 日期（精确到分/秒） | |
| 5 | 经手人 | 单行文本 | （若有"成员"类型也行，先文本最省事） |
| 6 | 结果单价 | 数字 | 允许小数 |
| 7 | 离散度 | 数字 | 允许小数 |
| 8 | 归属人 | 单行文本 | （将来配权限用；先文本） |
| 9 | 归属组 | 单行文本 | （将来配权限用；先文本） |
| 10 | 快照 | **多行文本** | ⭐ 就是存那份 12KB JSON 的地方，一定要"多行文本" |

**权限先不用配**——第一步只要：表建好、能手动加一行、把那份 JSON 粘进"快照"字段能存下，就够了。

## 第三步：建好后，把这几样发我（我写代码要用）

1. **凭据**（在宜搭/钉钉的「开发者后台」或应用「设置-开发配置」里找）：
   - AppKey / AppSecret（或叫 应用 Key / 密钥），
   - 有的地方还要一个 **SystemToken / 应用秘钥**（宜搭应用里的"表单/应用编号"旁边常有）。
   - 找不到就把那个设置页**截图发我**，我帮你认哪个是哪个。
2. **表单编号 formUuid**（打开这张台账表的设计页，地址栏或"表单信息"里有一串 `FORM-xxxxxxxx`）。
3. **你的钉钉 userId**（一般在通讯录里点自己能看到，或截图发我）。

> ⚠️ 凭据是密码性质的东西。你可以私下发我，我会让程序从环境变量读、**绝不写进代码、绝不提交到仓库**。

## 我拿到后做什么

用这些跑一个"冒烟测试"：程序自动往你这张台账表**写一行**（含那份快照 JSON）、再**读回来**核对。通了就证明"本地 ↔ 宜搭"这条路打通，剩下实例库/基础表/编号照着接。

字段的"字段标识"（像 `textField_xxx`）你不用手抄——我的脚本会自动去宜搭把表结构拉下来、按字段名对上。
