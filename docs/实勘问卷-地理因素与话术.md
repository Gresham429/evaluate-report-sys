# 实勘问卷 · 地理位置类因素 + 话术模版（草稿，待执业估价师定稿）

> 用途：移动端实勘问卷的「智能预填」——现场手机 GPS 坐标 → 地图 POI/地理编码接口 → 把**事实**填进
> 这些地理因素的描述里，加速录入。
>
> **两条硬线**：
> 1. **接口只给事实、不定档次**（§8 铁律）：话术里 `{事实}` 槽位可由接口预填（如"距最近地铁约 820 米"）；
>    `{档次/评价}` 槽位（好/中/差、便捷/一般）是**估价师看了事实自己拍**，接口不碰。
> 2. **话术是草稿**：下列措辞供起草参考，**法定文书用语须执业估价师定稿**，不由建设方或系统拍板。
>
> 因素清单据真实基础表（`比较因素条件说明表（基础表）`）提取，全 7 类核对无误。

## 一、按类别：哪些因素是「地理位置类」（需智能预填）

每类的 28（或 27）个因素里，下面这些是地理/区位类（其余是实物、权益、自然条件，与坐标无关）：

| 类别 | 地理位置类因素（序号照基础表） |
|---|---|
| **农用地** | 离城中心距离、离高速口距离、离水源地距离、临街状况、临路状况、临路宽度、临街道路等级、周边劳动力、基础设施、公共服务设施 |
| **办公** | 重要场所距离、临街状况、办公聚集度、离地铁距离、道路通达度、200米内公交线路数、基础设施、公共服务设施 |
| **商业** | 重要场所距离、临街状况、临街道路人流量、商铺聚集度、离地铁距离、道路通达度、200米内公交线路数、基础设施、公共服务设施 |
| **住宅** | 重要场所距离、临街状况、小区聚集度、离地铁距离、道路通达度、200米内公交线路数、基础设施、公共服务设施 |
| **工业** | 离城中心距离、离高速口距离、劳动力聚集度、产业聚集度、临街状况、临路宽度、临街道路等级、基础设施、公共服务设施 |
| **停车场用地** | 重要场所距离、商业繁华程度、临街状况、附近停车场数量、附近车流量、临路状况、临路宽度、临街道路等级、周边停车需求、基础设施、公共服务设施 |
| **建设用地** | 离城中心距离、离高速口距离、劳动力聚集度、产业聚集度、临街状况、临路状况、临路宽度、临街道路等级、基础设施、公共服务设施 |

（`维修费用承担/是否转租/相邻关系/使用限制` 等是权益类，`楼层/朝向/建筑结构/新旧程度/土壤/地形/灌溉` 等是实物/自然类——都不属地理，不在预填范围。）

## 二、话术模版（按因素，注明适用类别 + 接口能填什么）

约定：`{事实=接口}` 接口可预填；`{评价=估价师}` 估价师定；措辞待定稿。

### 距离/交通类（地图接口最能帮）

1. **离城中心距离 / 重要场所距离**（全部 7 类，序号 1）
   模版：`估价对象距{区域中心/CBD名称=接口}约{距离=接口}公里，区位条件{评价=估价师}。`
   接口：GPS → 反查所在行政区中心 / 最近商圈，算直线或驾车距离。

2. **离高速口距离**（农用/工业/建设用地）
   模版：`距最近高速出入口（{高速口名称=接口}）约{距离=接口}公里，对外交通{评价=估价师}。`

3. **离地铁距离**（办公/商业/住宅）
   模版：`距最近轨道交通站点（{站名=接口}）约{距离=接口}米，轨道交通{评价=估价师}。`

4. **离水源地距离**（农用）
   模版：`距最近水源地（{水源名=接口}）约{距离=接口}公里，灌溉取水{评价=估价师}。`

5. **200米内公交线路数**（办公/商业/住宅）
   模版：`估价对象 200 米范围内有公交站点{站点数=接口}处、公交线路{线路数=接口}条（{线路清单=接口}），公交出行{评价=估价师}。`

6. **道路通达度**（办公/商业/住宅）
   模版：`周边有主干道{干道数=接口}条（{道路名清单=接口}），道路通达度{评价=估价师}。`

7. **临街道路等级**（农用/工业/建设用地/停车场用地）
   模版：`估价对象临{道路名=接口}，属{主干道/次干道/支路=接口}，道路等级{评价=估价师}。`

8. **临路宽度**（农用/工业/建设用地/停车场用地）
   模版：`临路（{道路名=接口}）宽约{宽度=接口}米，{评价=估价师}。`（宽度接口给的是参考值，现场应核。）

### 周边配套 / 繁华度类（接口给 POI 密度作事实）

9. **公共服务设施**（全部 7 类）
   模版：`周边 1 公里内有{学校数=接口}所学校、{医院数=接口}家医疗机构、{商场数=接口}处商业、{银行/公园等=接口}，公共服务设施{评价=估价师}。`

10. **基础设施**（全部 7 类，"七通一平"类）
    模版：`地块{通水/通电/通路/通讯…=接口辅助+现场核}，达到{七通一平/六通一平=估价师}。`（接口只作辅助，以现场为准。）

11. **商业繁华程度**（停车场用地）
    模版：`周边 500 米内商业 POI {数量=接口}处（{代表性商业=接口}），商业繁华程度{评价=估价师}。`

12. **各类聚集度**（办公聚集度/商铺聚集度/小区聚集度/产业聚集度/劳动力聚集度/周边劳动力）
    模版：`周边同类{办公楼/商铺/住宅小区/工业企业=接口}分布{密集程度=接口POI密度}，聚集度{评价=估价师}。`
    接口：按类别搜对应 POI（写字楼/商铺/小区/工厂）的周边数量作事实。

13. **附近停车场数量 / 周边停车需求 / 附近车流量**（停车场用地）
    模版：`周边 500 米内停车场{数量=接口}处、主要车流来源为{商圈/枢纽=接口}，停车供需{评价=估价师}。`
    （车流量、停车需求接口只能间接提示，主要靠现场判断。）

### 临街 / 人流类（接口弱，以现场为准）

14. **临街状况 / 临路状况**（多数类）
    模版：`估价对象{东/南/西/北=现场}临{道路名=接口}，为{几面临街=现场}。`
    （几面临街是现场观察，接口只能给相邻道路名作参考。）

15. **临街道路人流量**（商业）
    模版：`所临{道路名=接口}为{商圈主街/次街=接口}，日常人流量{评价=估价师}。`（人流量以现场为准。）

## 三、给问卷/预填的落地建议

- 现场进问卷时先取一次 GPS，**一键预填**上面所有 `{事实=接口}` 槽位；估价师逐条核对、改错、再定档次。
- 预填内容一律**标注"接口自动获取，请核对"**，且**可改**（保留事实、判断交给人）。
- 预填的事实一经估价师确认，**随实勘数据存进快照**；出报告时用存的那份，不在渲染时重查接口（铁律 #5/#6 可复现）。
- 每类只对本类"地理位置类因素"清单（§一）做预填，其余因素不动。

## 四、待办 / 待定

- **话术定稿**：以上措辞是草稿，须执业估价师逐条改成法定文书用语（§8）。
- **接口选型**：高德 / 百度地图 POI 周边搜索 + 逆地理编码；距离用直线还是驾车，须统一口径。
- **"距离→档次"不自动映射**：如"距地铁 820 米"落到哪个档次由估价师定，系统不给推荐（铁律 #7）。
