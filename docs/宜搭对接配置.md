# 宜搭对接配置（怎么拿凭据、填哪、怎么跑）

> 目标：让本地程序能读写公司钉钉宜搭里的表。这份是"照着配"的清单。
> 配置完把 5~6 个值填进仓库根 `.env`，跑 `tools/yida_smoke.py` 验证联通。

## 0. 前提：宜搭必须是「专业版」及以上

**宜搭免费版、轻享版（2988/年）都不支持 OpenAPI**，程序连不进去。**专业版（5988/年起）才有**。
2026-07-18 实测：拿测试用的**免费**组织跑，接口报「您组织使用的宜搭『免费版』，暂不支持使用 openApi」。
公司付费的宜搭是**另一个组织**——务必在**那个付费组织**里建表、取凭据（下面每一步都指它）。

## 1. 要凑齐的 6 个值（都在付费组织里取）

| # | 值 | 在哪拿 | 性质 |
|---|---|---|---|
| 1 | **AppKey**（Client ID） | 钉钉开发者后台 open-dev.dingtalk.com → 你的企业内部应用 →「凭证与基础信息 / 应用凭证」 | 公开 |
| 2 | **AppSecret**（Client Secret） | 同上，Client Secret 那行点**复制**（显示是打码的，复制到的是完整值）。**别点旁边的重置 ↻** | **机密** |
| 3 | **appType**（应用编码，`APP_` 开头） | 宜搭 → 该应用 →「设置 / 部署运维」页的「应用编码」 | 公开 |
| 4 | **SystemToken**（应用密钥） | 同「部署运维」页的「应用密钥」，点复制取完整值 | **机密** |
| 5 | **formUuid**（台账表单编号，`FORM-` 开头） | 「部署运维」页会列出各表单的编码；或打开台账表，地址栏里的 `FORM-xxxx` | 公开 |
| 6 | **userId**（你的钉钉 userId） | 「部署运维」页的「当前登录人ID」；或钉钉通讯录点自己 | 公开 |

**AppKey/AppSecret 来自哪个应用**：一个**钉钉企业内部应用**（在开发者后台建/看），且要给它开通**宜搭相关的 API 权限**
（应用「权限管理」里搜"宜搭"/"yida"）。没有就建一个（需组织管理员；不会弄可让 IT 代劳）。
第一次跑冒烟若报"没权限"，按报错去开对应权限即可。

> 建台账表本身怎么点：见 [宜搭建表清单-台账.md](宜搭建表清单-台账.md)（10 个字段、每个选什么类型）。

## 2. 填进 `.env`（仓库根，已 gitignore、不会提交）

在 `估价报告系统/.env` 里填（没有就新建）：

```dotenv
YIDA_APP_KEY=<第1个：AppKey>
YIDA_APP_SECRET=<第2个：AppSecret 完整值>
YIDA_APP_TYPE=<第3个：APP_xxxx>
YIDA_SYSTEM_TOKEN=<第4个：应用密钥完整值>
YIDA_FORM_UUID=<第5个：FORM-xxxx>
YIDA_USER_ID=<第6个：userId>
```

- `.gitignore` 第 14 行是 `.env`，所以它**永远不会进仓库**。`tools/yida_smoke.py` 会自动读它。
- 机密（AppSecret、SystemToken）**只放这里**，别写进任何会提交的文件。

## 3. 跑冒烟测试验证联通

```bash
cd 估价报告系统
uv run python tools/yida_smoke.py
```

脚本会：① 取 accessToken ② 拉台账表字段结构 ③ 写一行（含快照样例）④ 读回来。
- **全部 200 / 有数据返回** = 联通成功，可以进下一步（写正式宜搭适配器）。
- 报错就把整段输出发我，我据真实报错校准接口端点/参数（宜搭老/新接口、字段标识对应）。

## 4. 联通之后（本地已备好，等这一步）

三个 Store 的「可插拔后端」已并 main（`src/{ledger,knowledge_base,library}/backend.py`），各带一个**内存后端**
作为宜搭适配器要满足的**可执行契约**。联通后：照契约写 `Yida*Backend`（append/读表）→ 用 `backend=` 挂上去 →
再做登录鉴权、按人裁剪缓存、报告编号（宜搭流水号）。设计见
[宜搭数据模型与权限](superpowers/specs/2026-07-17-宜搭数据模型与权限.md)。

## 5. 安全

- 机密只在 gitignored 的 `.env`。若密钥在别处（聊天、截图）暴露过，联通稳定后到钉钉后台**重置一次密钥**、更新 `.env`。
- 数据出本机进公司钉钉属合规事项，须贵司合规确认（钉钉 design §4 铁律 #9）。
