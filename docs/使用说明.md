# 使用说明

## 启动

双击 `估价报告系统.exe`，浏览器会自动打开。全程本地运行，不联网、不上传任何数据。

## 四步

1. **选 Excel** —— 拖入或点击选择「实勘表、比较法.xlsx」
2. **复核数据** —— 检查自动提取的字段，可直接修改；留意黄色校验提示
3. **挑附件** —— 选择图片或 PDF，拖拽调整顺序；没有附件可以跳过
4. **生成** —— 下载 .docx，在 Word 里润色定稿

## 重要约束

**改完 Excel 一定要保存再导入。** 系统读的是 Excel 存储的计算结果，
不保存就导入，读到的是上次保存时的旧值。

**复核界面的修改只影响本次报告，不会写回 Excel。**
这是有意为之：Excel 是一张公式网，回写单个值会打断公式链、
把计算结果变成死数。发现数据有误，请回 Excel 修改、保存、重新导入。

**校验提示只是提示，不阻止生成。** 是不是问题、要不要改，由你判断。

## 改措辞

- **法定套话**（估价师声明、假设限制条件、估价原则等三类通用的文字）
  → 改 `copy.yaml`，改一处三类同步
- **类别专属内容与格式** → 直接在 `templates/农用.docx` 等文件里用 Word 改

改完不用重新编译，下次生成即生效。
