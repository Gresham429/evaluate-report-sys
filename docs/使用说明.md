# 使用说明

## 启动

双击 `估价报告系统.exe`，浏览器会自动打开。**全程本地运行，不联网、不上传任何数据。**

界面有三个页签：

| 页签 | 做什么 | 多久用一次 |
|---|---|---|
| **出报告** | 填表、选实例、重算、生成 docx | 每份报告 |
| **实例库** | 累积比较实例，供出报告时挑选 | 遇到新成交案例时 |
| **基础表** | 导入估价知识（因素、档次、修正系数） | 改了系数才用 |

## 第一次用：先导基础表

**基础表是估价知识本身**——28 个比较因素、每个因素 5 档描述、每差一档的修正系数。
没有它，表单给不出档次选项，也算不出结果。

到「基础表」页，选类别，导入对应的 Excel（如 `办公实勘表、比较法.xlsx`）。
三类各导一次。

导完就不用再管了，**除非你改了系数**——那时重导一次。

## 出一份报告（七步）

```
壹 开始        新建空白表单，或导入 Excel 预填
贰 基本信息    19 项，全部人工填
叁 一览表      估价对象，可增删行
肆 因素档次    28 个下拉框，选项来自基础表
伍 选可比实例  勾三条 + 逐条填市场状况指数 → 重算 → 用此结果更新一览表
陆 附件        图片或 PDF，可跳过
柒 生成下载    .docx，在 Word 里润色定稿
```

### 两条入口，进的是同一张表单

- **新建空白表单** —— 从头填。
- **导入 Excel 预填** —— 传一份填好的「实勘表、比较法.xlsx」，19 项字段、一览表、
  28 个档次一次填好，之后照常在表单里改。

**导入只是替你把表单填一遍，不是另一条路。** 填完之后两者完全一样。

### 第伍步：重算

勾中三条实例，**逐条填市场状况指数**。

> **系统不推算、不给默认值。** 市场状况指数是「实例成交日期 × 本项目价值时点」的
> 判断，只有你能定。不填就报错，不会静默取个 100 继续算。
>
> **系统也不做可比性推荐**——哪条更可比，由你的专业判断决定。列表只按租期起始日
> 从新到旧排，不打分、不高亮。

算完点「用此结果更新一览表」，评估结果才会写进一览表的单价，报告印的就是这个数。

### 单价可以改

一览表的单价填进去之后**可以直接改**。比如农用算出 1399.26，你要按 1400 写进报告，
改就是了——**取整与否是你的判断，系统不替你决定**。改完年租赁价值自动跟着算。

## 实例库

比较实例是**低频累积的公司资产**，与单份报告无关。两种录入方式：

- **从 Excel 批量导入** —— 传一份「实勘表、比较法.xlsx」，自动抽出里面的三条实例。
- **手工录入一条** —— 不必开 Excel。填位置、成交价、面积、租期，再选 28 个因素档次。

**编号、起始日、日期精度由系统据租期原文派生**，不用你填。

租期只知道年月就写 `2025.7-2026.7`，**不必编一个日子出来**——系统会标「⚠ 日期仅年月」，
把这个事实留在库里，选实例时你一眼能看到。

重复编号**不覆盖**：同位置同起始月的两条多半是重复录入，系统如实告诉你，不静默顶掉
已有的那条。

## 基础表版本

**Excel 是权威，系统存副本，改了重导一次。**

版本号是**内容指纹**（如 `95d043e06567`），不是人工填的——内容一变指纹即变，改不了
也伪造不了。人工填「v1.2」会忘、会填错、会复制粘贴时忘改。

- **同一份导两次** → 提示「未新增版本」，不堆重复。
- **改了系数再导** → 新指纹、新版本，**旧版本仍在**。
- 界面上「当前」标的就是现在用的那一版。

> **旧版本永不覆盖。** 2027 年回头复查 2026 年那份报告时，得能拿回当时那版基础表
> 把结果重算出来——「能复现」是可复查的前提。

## 草稿

**边填边存**，不用手动保存。填一半关了浏览器，下次打开在第壹步能看到「未完成的草稿」，
点「续填」接着填。

**附件不进草稿**（浏览器不允许保存文件本身），续填后须重挑。

## 重要约束

**改完 Excel 一定要保存再导入。** 系统读的是 Excel 存储的计算结果，不保存就导入，
读到的是上次保存时的旧值。**导入基础表同理**——修正系数在表里是公式，不保存就读到旧值。

**表单里的修改只影响本次报告，不写回 Excel。** 这是有意为之：Excel 是一张公式网，
回写单个值会打断公式链、把计算结果变成死数。

**校验提示只是提示，不阻止生成。** 是不是问题、要不要改，由你判断。系统会替你核，
但不替你改，也不替你填。比如：

```
规模字段写「房屋建筑面积732.69平方米」
一览表面积合计 723.69
→ ⚠ 规模字段写的 732.69 平方米，与一览表面积合计 723.69 不符，请复核
```

**三个实例的权重写死各 ⅓**，本版不可调。

## 改措辞

- **法定套话**（估价师声明、假设限制条件、估价原则等三类通用的文字）
  → 改 `copy.yaml`，改一处三类同步
- **类别专属内容与格式** → 直接在 `templates/农用.docx` 等文件里用 Word 改
- **因素、档次、修正系数** → 改 Excel 基础表，到「基础表」页重导一次

## 数据放在哪

```
data/
├── 实例库.json      ← 比较实例
├── 草稿/            ← 未完成的表单
└── 基础表/          ← 各版基础表 + 台账（哪版、何时、从哪个文件导入）
```

都是纯文本 JSON，**可以直接打开看、手改、备份**。
